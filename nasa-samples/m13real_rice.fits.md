# m13real_rice.fits

**Source**: Not on the NASA GSFC FITS samples page (https://fits.gsfc.nasa.gov/fits_samples.html does not list it). This copy is byte-identical to `samples/fits.gsfc.nasa.gov/m13real_rice.fits` in the fitsrs test-file tarball (https://alasky.cds.unistra.fr/Aladin-Lite-test-files/fits-rs-test-files.tar) and to `src/test/resources/nom/tam/image/provided/m13real_rice.fits` in nom-tam-fits (https://github.com/nom-tam-fits/nom-tam-fits/tree/master/src/test/resources/nom/tam/image/provided). The header CHECKSUM comments date the file to 2006-11-15. No earlier origin was found.

**Instrument/Mission**: SkyView virtual observatory survey image of globular cluster Messier 13 (M13, NGC 6205). The image was generated by the SkyView survey analysis system.

**Object**: M13 (RA 250.4226, Dec +36.4602).

## HDU Structure

| HDU | Type     | Dimensions     | EXTNAME          | Description                                                 |
|-----|----------|----------------|------------------|-------------------------------------------------------------|
| 0   | Primary  | (empty)        |                  | Minimal header                                               |
| 1   | BINTABLE | 3 cols x 300   | COMPRESSED_IMAGE | RICE_1 compressed image (original: 300 x 300, BITPIX = -32) |

## FITS Features Exercised

- FITS tile compression with RICE_1 algorithm on floating-point data
- Quantized float-to-int with NOISEBIT = 4 (lossy compression), given as ZNAME2/ZVAL2; there is no ZQUANTIZ keyword, so the default (no dithering) applies
- Per-tile ZSCALE/ZZERO columns for float reconstruction
- Variable-length array column (1PB) with heap storage
- CHECKSUM/DATASUM integrity verification keywords

**File size**: 100,800 bytes (98 KB)
