# m13_gzip.fits

**Source**: Not on the NASA GSFC FITS samples page (https://fits.gsfc.nasa.gov/fits_samples.html does not list it). This copy is byte-identical to `samples/fits.gsfc.nasa.gov/m13_gzip.fits` in the fitsrs test-file tarball (https://alasky.cds.unistra.fr/Aladin-Lite-test-files/fits-rs-test-files.tar) and to `src/test/resources/nom/tam/image/provided/m13_gzip.fits` in nom-tam-fits (https://github.com/nom-tam-fits/nom-tam-fits/tree/master/src/test/resources/nom/tam/image/provided). The header CHECKSUM comments date the file to 2006-11-15. No earlier origin was found.

**Instrument/Mission**: SkyView virtual observatory survey image of globular cluster Messier 13 (M13, NGC 6205). The image was generated by the SkyView survey analysis system.

**Object**: M13 (RA 250.4226, Dec +36.4602).

## HDU Structure

| HDU | Type     | Dimensions     | EXTNAME          | Description                                        |
|-----|----------|----------------|------------------|----------------------------------------------------|
| 0   | Primary  | (empty)        |                  | Minimal header                                      |
| 1   | BINTABLE | 1 col x 300    | COMPRESSED_IMAGE | GZIP_1 compressed image (original: 300 x 300, 16-bit) |

## FITS Features Exercised

- FITS tile compression with GZIP_1 algorithm
- Variable-length array column (1PB) with heap storage
- CHECKSUM/DATASUM integrity verification keywords
- 300 x 1 tile size (row-by-row compression)
- Integer image compression (ZBITPIX = 16)
- Decodes to exactly the same 300 x 300 int16 pixels as `m13_rice.fits`

**File size**: 123,840 bytes (121 KB)
