# glg_tte_n0_200524_05z_v00.fit.gz

**Source**: Fermi GBM daily data at HEASARC (https://heasarc.gsfc.nasa.gov/FTP/fermi/data/gbm/daily/2020/05/24/current/)

**License**: NASA mission data, publicly released with no usage restrictions.

**Instrument/Mission**: Fermi Gamma-ray Space Telescope (GLAST), Gamma-ray Burst Monitor, NaI detector 0 (`NAI_00`).

**Description**: One hour (2020-05-24 05:03:37 to 05:59:59 UTC) of continuous time-tagged event (TTE) data: every photon the detector recorded, with its arrival time and energy channel. The hour contains GBM trigger bn200524211 (GRB 200524211, trigger time 611989445.358 MET, 05:03:43 UTC). This is the file shape the [blink](https://github.com/hx-guo/blink) burst-search pipeline reads in `blink_fermi_gbm/src/io/tte.rs`: `EVENTS` `TIME` (`f64`) and `PHA` (`i16`), then `GTI` `START`/`STOP`.

The whole file is gzip-compressed, exactly as HEASARC distributes it; cfitsio opens it transparently.

## HDU Structure

| HDU | Type     | Dimensions            | EXTNAME | Description                                   |
|-----|----------|-----------------------|---------|-----------------------------------------------|
| 0   | Primary  | (empty)               |         | Observation metadata                          |
| 1   | BINTABLE | 3 cols x 128 rows     | EBOUNDS | Energy bounds per channel: `CHANNEL` (1I), `E_MIN`/`E_MAX` (1E, keV) |
| 2   | BINTABLE | 2 cols x 3,536,325 rows | EVENTS | Photon events: `TIME` (1D, s), `PHA` (1I)    |
| 3   | BINTABLE | 2 cols x 1 row        | GTI     | Good time interval: `START`, `STOP` (1D, s)   |

## FITS Features Exercised

- Whole-file gzip compression (`.fit.gz`), not tile compression
- `TZERO` on a double column: `EVENTS` `TIME` has `TZERO1 = 611989422.9725`, so physical times are raw values plus about 6.1e8 s
- A large binary table (3.5 million rows, 10 bytes per row)
- Named extensions looked up by `EXTNAME`
- Empty primary HDU

**File size**: 19,186,989 bytes (18.3 MB) compressed; 35,389,440 bytes (33.7 MB) uncompressed
