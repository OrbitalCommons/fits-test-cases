**Description**: A second-batch (`_001`) MWAX correlator file for coarse channel 114 of observation 1244973688, made from [`1244973688_20190619100110_ch114_000.fits`](1244973688_20190619100110_ch114_000.fits.md) for mwalib issue #45 (a panic when only second-batch files were given). The two files differ in 6 bytes, all in header cards: `MARKER = 10` instead of `0` and `TIME = 1560938480` instead of `1560938470`, in the primary header and in both image HDUs. The compressed data are the same bytes, so the decoded visibilities and weights are identical to the `_000` file's; see that file's document for the structure and the compression.

Git stores it as a delta of the `_000` file, so it adds little to a clone's pack size.

**Instrument/Mission**: Murchison Widefield Array (MWA), MWAX correlator
