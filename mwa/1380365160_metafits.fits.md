## FITS Features Exercised

- Numeric cards read as strings and parsed as integer lists ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143)): `CHANNELS = '62,63,…,85'` with 2-digit channels, `CENTCHAN = 74`
- A string value with a leading underscore and a space (`FILENAME = '_PSR J1921+2153_Ch74'`)
- NUL-padded string cells ([fitsio-pure#144](https://github.com/OrbitalCommons/fitsio-pure/issues/144)): all 288 `TileName`, `Length` and `Receiver_Types` cells and 284 of 288 `Flavors` cells
- CONTINUE long strings without `LONGSTRN` (`CHANNELS`)
