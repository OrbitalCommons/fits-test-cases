**Description**: Metafits for an MWAX beamformer observation (`MODE = 'MWAX_BEAMFORMER'`, `FILENAME = 'Mondal2025A_reg_Sun_Ch[58,61,...,210,226]_27_of_75'`, 2025-12-10T03:43:58, 240 s) of the Sun, with 24 coarse channels spread from 58 to 226 (about 74 to 289 MHz), 160 kHz fine channels and 0.25 s integrations. 184 tiles (`NINPUTS = 368`), metafits version 2.4, written by the scheduler (`rediscontroller.py`) ten seconds after the start.

It has the correlator delay-mode keys (`DELAYMOD = 'FULLTRACK'`, `CABLEDEL = 1`, `GEODEL = 3`) but none of the beamformer ones (`BDELMOD` …), and an early VOLTAGEBEAMS layout: the table has **no rows** (`NAXIS2 = 0`), and its `tileset` column is `250A` (a string) where later files have `256I`. The CALIBDATA table names its columns `Calib_Delay` and `Calib_Gains`, like [`1458492896_metafits.fits`](1458492896_metafits.fits.md) and unlike [`1348608128_metafits.fits`](1348608128_metafits.fits.md) (`delay_m`, `gains`); its header identifies the fit (`CALFIT = 1765315943773165`, `CALFITID = 1765315943`, `CALOBSID = 1449348632`, `TAROBSID = 1449373456`, `CALCDVER = '1.0.80'`) and has `FILENAME=  / Hyperdrive fit filename` with no value.

## FITS Features Exercised

- A binary table with zero rows (`NAXIS2 = 0`, no data unit) between tables that have data
- Optional keys that are absent (`BDELMOD`, `BCABDEL`, `BGEODEL`, …): each lookup must fail cleanly so mwalib can record `None`
- A keyword with no value (`FILENAME=` in CALIBDATA), and a 16-digit integer beyond 32 bits (`CALFIT`) read as a string ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143))
- Mixed-case column names that vary across tables and files ([fitsio-pure#145](https://github.com/OrbitalCommons/fitsio-pure/issues/145)): CALIBDATA `Calib_Delay` where newer files have `delay_m`, so mwalib's first lookup must fail with COL_NOT_FOUND
- NUL-padded string cells ([fitsio-pure#144](https://github.com/OrbitalCommons/fitsio-pure/issues/144)) in TILEDATA, CALIBDATA and SIGCHAINDATA
- Six HDUs; CONTINUE long strings without `LONGSTRN`
