# 1096952256_metafits.fits

**Source**: MWATelescope/mwalib test suite (https://github.com/MWATelescope/mwalib), `test_files/metafits_signal_chain_corr/1096952256_metafits.fits` (byte-identical)

**License**: MPL-2.0

**Description**: MWA metafits file with signal chain correction data. In addition to the standard TILEDATA binary table, this file includes a SIGCHAINDATA extension that stores signal chain correction coefficients: 8 rows, one per receiver type (`RRI`, `NI`, `SHAO`, `PSEUDO`) and whitening filter setting (0 or 1), each holding 256 `Corrections` values. Used by mwalib to test signal chain correction parsing.

**Instrument/Mission**: Murchison Widefield Array (MWA)

## HDU Structure

| HDU | Type     | Dimensions          | EXTNAME       | Description                              |
|-----|----------|---------------------|---------------|------------------------------------------|
| 0   | Primary  | (empty)             |               | Observation metadata                     |
| 1   | BINTABLE | 21 cols x 256 rows  | TILEDATA      | Antenna/tile metadata with 21 columns    |
| 2   | BINTABLE | 3 cols x 8 rows     | SIGCHAINDATA  | Signal chain corrections per receiver type and whitening filter |

## FITS Features Exercised

- Multi-extension file with two binary tables
- Wide rows (2059 bytes/row in SIGCHAINDATA)
- Array-in-cell columns with large repeat counts (`Corrections` is `256D`)
- CONTINUE long-string convention (CHANNELS spans three cards, the last an empty `''` carrying the comment)
- A keyword with no value (`DELAYMOD=` followed only by a comment)
- Named extensions (EXTNAME = TILEDATA, SIGCHAINDATA)
- Empty primary HDU
