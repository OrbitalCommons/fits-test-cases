# 1096952256_metafits.fits

**Source**: MWATelescope/mwalib test suite (https://github.com/MWATelescope/mwalib)

**License**: MPL-2.0

**Description**: MWA metafits file with signal chain correction data. In addition to the standard TILEDATA binary table, this file includes a SIGCHAINDATA extension that stores per-receiver signal chain correction coefficients. Used by mwalib to test signal chain correction parsing.

**Instrument/Mission**: Murchison Widefield Array (MWA)

## HDU Structure

| HDU | Type     | Dimensions          | EXTNAME       | Description                              |
|-----|----------|---------------------|---------------|------------------------------------------|
| 0   | Primary  | (empty)             |               | Observation metadata                     |
| 1   | BINTABLE | 21 cols x 256 rows  | TILEDATA      | Antenna/tile metadata with 21 columns    |
| 2   | BINTABLE | 3 cols x 8 rows     | SIGCHAINDATA  | Signal chain correction coefficients per receiver |

## FITS Features Exercised

- Multi-extension file with two binary tables
- Wide rows (2059 bytes/row in SIGCHAINDATA)
- Array-in-cell columns with large repeat counts
- Named extensions (EXTNAME = TILEDATA, SIGCHAINDATA)
- Empty primary HDU
