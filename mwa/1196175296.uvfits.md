## FITS Features Exercised

- Random groups: reading parameters unscaled (`ffggpe`) and data scaled (`ffgpve`), one group or many groups in one call, seek-based ([fitsio-pure#152](https://github.com/OrbitalCommons/fitsio-pure/issues/152)); hyperdrive reads `num_rows × pcount` parameters at once
- A reference for writing random groups with `PTYPEn`/`PSCALn`/`PZEROn` and appending an extension after them ([fitsio-pure#96](https://github.com/OrbitalCommons/fitsio-pure/issues/96), [#97](https://github.com/OrbitalCommons/fitsio-pure/issues/97)): Marlu's writer must reproduce this file's layout
- `PZERO5` on the `DATE` parameter (a Julian date split between header and data)
- `COMMENT` text longer than one card, split by cfitsio `ffpcom` into 72-character cards mid-word (cotter's command line) ([fitsio-pure#149](https://github.com/OrbitalCommons/fitsio-pure/issues/149))
- `HISTORY AIPS WTSCAL =  1.0`, a commentary card that looks like a keyword
- String-valued numbers (`FIBRFACT = '2.0'`) and an all-blank string (`METAVER = '        '`) read with `read_key::<String>` ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143))
- An `EXTNAME` with a space (`AIPS AN`) and AIPS keywords (`ARRAYX`/`Y`/`Z`, `GSTIA0`, `DEGPDY`, `RDATE`, …)
- Table reads on the AN table without loading the 7 MB of groups before it ([fitsio-pure#153](https://github.com/OrbitalCommons/fitsio-pure/issues/153): the 128 `ANNAME` values raised RSS by 6.9 MB on fitsio-pure 0.22.0)
- fitsverify warnings, as for all cotter and Birli output: `EPOCH` is deprecated, and axis 1 has no `CTYPE1`/`CRVAL1`/`CRPIX1`
