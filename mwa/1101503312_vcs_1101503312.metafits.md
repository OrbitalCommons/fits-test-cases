**Description**: The metafits mwalib uses for its legacy VCS (`VCSLegacyRecombined`) voltage-context tests. Per mwalib's `test_files/1101503312_vcs/README.md`, it is the metafits of observation 1101503312 (a Phase 1 correlator observation, `MODE = 'HW_LFILES'`, 2014-12-01T21:08:16, 112 s) cut down to 2 RF inputs (one tile, `Tile011`), so that the voltage files the tests generate stay small. The tests write their own `.dat` voltage files; none are stored.

The cut was made by hand in fv (`HISTORY File modified by user 'gsleap' with fv  on 2023-08-17T10:29:36` in TILEDATA). Compared with [`1101503312.metafits`](1101503312.metafits.md), TILEDATA has 2 rows instead of 256, and the primary header's `NINPUTS` became a quoted string, `NINPUTS = '2       '`, where the original has the integer `256`. Its MWAX VCS twin, [`1101503312_mwax_vcs_1101503312.metafits`](1101503312_mwax_vcs_1101503312.metafits.md), differs from it in 10 bytes: the integer `NINPUTS = 2` and the HISTORY date.

The same mwalib directory also has `1101503312.metafits128`, which is byte-identical to [`1101503312.metafits`](1101503312.metafits.md) and so is not repeated here; `test_context_legacy_v1_128_tiles` uses it.

**Instrument/Mission**: Murchison Widefield Array (MWA), 128-tile Phase 1, legacy VCS test metadata

## FITS Features Exercised

- A number stored as a quoted string: `NINPUTS = '2       '`. mwalib reads every key as a string and parses it ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143) covers the reverse case, numeric cards read as strings), so the string value must come back as `2`, without its trailing blanks
- NUL-padded string cells: `TileName` = `Tile011\0`, `Length` = `EL_-656.14\0\0\0\0`, `Flavors` = `RG6_90\0\0\0\0` ([fitsio-pure#144](https://github.com/OrbitalCommons/fitsio-pure/issues/144))
- A file edited by hand in fv: a two-row table cut from a 256-row one, with an fv HISTORY card
- CONTINUE long strings without `LONGSTRN` (`CHANNELS`)
- Array-in-cell columns (`Gains` 24I, `Delays` 16I)
