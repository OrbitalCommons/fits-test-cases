**Description**: The metafits mwalib uses for its non-oversampled MWAX VCS (`VCSMWAXv2`) voltage-context tests. Per mwalib's `test_files/1101503312_mwax_vcs/README.md`, it is a metafits cut down to 2 RF inputs (one tile, `Tile011`) to keep the generated test voltage files small. The tests write their own `.sub` files; none are stored.

The observation itself is the 2014 Phase 1 correlator observation 1101503312 (`MODE = 'HW_LFILES'`, `INSTRUME = '128T'`, 112 s): mwalib takes the MWAX VCS format from the voltage files it is given, not from this header. It was edited in fv (`HISTORY File modified by user 'gsleap' with fv  on 2023-08-16T17:00:49`) and differs from the legacy VCS copy, [`1101503312_vcs_1101503312.metafits`](1101503312_vcs_1101503312.metafits.md), in only 10 bytes: here `NINPUTS = 2` is an integer, there it is the string `'2       '`.

**Instrument/Mission**: Murchison Widefield Array (MWA), MWAX VCS test metadata

- A two-row table cut by hand in fv
- CONTINUE long strings without `LONGSTRN` (`CHANNELS`)
