**Description**: Metafits in the newer layout with a CALIBDATA table, for MWAX correlator observation 1348608128 (`MODE = 'MWAX_CORRELATOR'`, 2022-09-30T21:21:50, 112 s, 136 tiles / 272 inputs, metafits version 2.4), regenerated by the web service on 2025-11-21 (`DATE`). The primary header also carries the calibration fit's identity (`CALFITID`, `CALCDVER`, `CALDTIME`, `CALCRTR`, `CALITERS`, `CALITLIM`).

Column names vary in case across its tables, and against older metafits:

| HDU | Column names |
|---|---|
| TILEDATA | `Input`, `Antenna`, `Tile`, `TileName`, `Pol`, `Rx`, `Slot`, `Flag`, `Length`, `North`, `East`, `Height`, `Gains`, `BFTemps`, `Delays`, `VCSOrder`, `Flavors`, `Calib_Delay`, `Calib_Gains`, `Receiver_Types`, `Whitening_Filter` |
| CALIBDATA | `Antenna`, `Tile`, `TileName`, `Pol`, **`delay_m`**, `intercept`, **`gains`**, `gains_pol1`, `gains_pol0`, `phase_fit_quality`, `gains_fit_quality` |
| SIGCHAINDATA | **`Receiver_type`**, `Whitening_Filter`, **`Corrections`** |

mwalib looks columns up by names that do not always match this case: its test suite reads `corrections` from SIGCHAINDATA's `Corrections` (in [`1096952256_metafits.fits`](1096952256_metafits.fits.md), whose SIGCHAINDATA has the same columns), and SIGCHAINDATA's `Receiver_type` differs from TILEDATA's `Receiver_Types`. Its `calibration_fit` reads CALIBDATA's `delay_m`, falling back to `Calib_Delay` (the older name, still used by [`1458492896_metafits.fits`](1458492896_metafits.fits.md)) only if the first lookup fails.

## FITS Features Exercised

- Case-insensitive column lookup and status 219 (`COL_NOT_FOUND`) for a missing column ([fitsio-pure#145](https://github.com/OrbitalCommons/fitsio-pure/issues/145)): `corrections` must find `Corrections`; `Calib_Delay` is absent from CALIBDATA
- NUL-padded `A` cells, which cfitsio and astropy end at the first NUL ([fitsio-pure#144](https://github.com/OrbitalCommons/fitsio-pure/issues/144)); mwalib parses `Length` as a number after stripping `EL_`
- Numeric cards read as strings ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143)), and a keyword with no value (`FILENAME=  / Hyperdrive fit filename` in CALIBDATA)
- A long string value that fills the card, followed by `/` and no comment (`FILENAME` in the primary)
- CONTINUE long strings without `LONGSTRN` (`CHANNELS`)
- A logical-byte column (`Whitening_Filter`, `B`) and wide array cells (`Corrections` 256D, `gains` 24E)
