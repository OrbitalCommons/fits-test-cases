# 1297526432_gpubox_ch117.fits

**Source**: MWATelescope/Marlu test suite (https://github.com/MWATelescope/Marlu), also used in MWATelescope/Birli (https://github.com/MWATelescope/Birli)

**License**: MPL-2.0

**Description**: Synthetic MWAX correlator output ("gpubox") file for coarse channel 117 (149.760 MHz). Contains alternating visibility and weight image extensions for each timestep. Part of a synthetic observation based on the MWAX HydA Gold Observation, limited to 2 antennas and 2 fine channels. Originally named `1297526432_20210216160014_ch117_000.fits` (byte-identical to `tests/data/1297526432_mwax/` in both Marlu and Birli; the `_000` file is the first of two batches, and upstream also has `_001`).

The pixel values are synthetic, not real visibilities: each visibility HDU holds consecutive integers (4259840 to 4259855 in the first row of HDU 1; HDU 3 continues from 4260096) and every weight is 1.0. The two timesteps carry the same `TIME = 1613491214` and differ only in `MILLITIM` (0 and 500).

**Instrument/Mission**: Murchison Widefield Array (MWA), MWAX correlator

## HDU Structure

Dimensions are NAXIS1 x NAXIS2. Per the primary header comments, visibilities are ordered `[baseline][finechan][pol][r,i]` (NAXIS1 = 2 fine channels x 4 pols x 2 = 16, NAXIS2 = 3 baselines including autocorrelations) and weights `[baseline][pol]` (NAXIS1 = 4 pols).

| HDU | Type    | Dimensions | EXTNAME | Description                              |
|-----|---------|------------|---------|------------------------------------------|
| 0   | Primary | (empty)    |         | Correlator metadata (time, channel, version) |
| 1   | IMAGE   | 16 x 3    |         | Visibility data (BITPIX=32, i32) for timestep 1 |
| 2   | IMAGE   | 4 x 3     |         | Weight/flag data (BITPIX=-32, f32) for timestep 1 |
| 3   | IMAGE   | 16 x 3    |         | Visibility data (BITPIX=32, i32) for timestep 2 |
| 4   | IMAGE   | 4 x 3     |         | Weight/flag data (BITPIX=-32, f32) for timestep 2 |

## FITS Features Exercised

- Multi-extension file with 4 image extensions
- Mixed BITPIX types across extensions (32 and -32)
- Alternating HDU pattern (data + weights)
- Small 2D image arrays
- Empty primary HDU
