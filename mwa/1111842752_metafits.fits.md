# 1111842752_metafits.fits

**Source**: MWATelescope/mwalib test suite (https://github.com/MWATelescope/mwalib)

**License**: MPL-2.0

**Description**: MWA metafits file with embedded calibration solution data. Contains the standard TILEDATA binary table plus a CALIBDATA extension with per-tile calibration Jones matrix elements. Used by mwalib to test calibration data reading.

**Instrument/Mission**: Murchison Widefield Array (MWA)

## HDU Structure

| HDU | Type     | Dimensions          | EXTNAME    | Description                              |
|-----|----------|---------------------|------------|------------------------------------------|
| 0   | Primary  | (empty)             |            | Observation metadata                     |
| 1   | BINTABLE | 21 cols x 256 rows  | TILEDATA   | Antenna/tile metadata with 21 columns    |
| 2   | BINTABLE | 6 cols x 256 rows   | CALIBDATA  | Per-tile calibration solutions (Jones matrices) |

## FITS Features Exercised

- Multi-extension file with two binary tables
- Named extensions (EXTNAME = TILEDATA, CALIBDATA)
- Calibration data with float columns
- Array-in-cell columns
- Empty primary HDU

**File size**: 115,200 bytes (112.5 KB)
