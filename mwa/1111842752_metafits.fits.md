# 1111842752_metafits.fits

**Source**: MWATelescope/mwalib test suite (https://github.com/MWATelescope/mwalib), `test_files/metafits_cal_sol/1111842752_metafits.fits` (byte-identical)

**License**: MPL-2.0

**Description**: MWA metafits file with embedded calibration solution data (HydA calibrator observation). Contains the standard TILEDATA binary table plus a CALIBDATA extension with one row per tile and polarisation (128 tiles x `X`/`Y`): `Antenna`, `Tile`, `TileName`, `Pol`, a cable delay `Calib_Delay` (`E`, m) and 24 real per-coarse-channel gains `Calib_Gains` (`24E`). CALIBDATA also carries fit provenance keywords (`CALFITID`, `CALOBSID`, `CALCDVER`, `CALDTIME`, `CALCRTR`, `CALITERS`, `CALITLIM`). Used by mwalib to test calibration data reading.

**Instrument/Mission**: Murchison Widefield Array (MWA)

## HDU Structure

| HDU | Type     | Dimensions          | EXTNAME    | Description                              |
|-----|----------|---------------------|------------|------------------------------------------|
| 0   | Primary  | (empty)             |            | Observation metadata                     |
| 1   | BINTABLE | 21 cols x 256 rows  | TILEDATA   | Antenna/tile metadata with 21 columns    |
| 2   | BINTABLE | 6 cols x 256 rows   | CALIBDATA  | Per-input calibration delay and gains     |

## FITS Features Exercised

- Multi-extension file with two binary tables
- Named extensions (EXTNAME = TILEDATA, CALIBDATA)
- Calibration data with float columns
- Array-in-cell columns (`Gains` 24I, `Delays` 16I, `Calib_Gains` 24E)
- CONTINUE long-string convention (CHANNELS spans three cards, the last an empty `''` carrying the comment)
- A keyword with no value (`DELAYMOD=` followed only by a comment)
- Empty primary HDU
