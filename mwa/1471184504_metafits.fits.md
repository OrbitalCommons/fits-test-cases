## FITS Features Exercised

- A `HIERARCH` keyword with a string value in a real instrument header ([fitsio-pure#102](https://github.com/OrbitalCommons/fitsio-pure/issues/102)): `HIERARCH REFERENCE = 'PSR_J1752-2806'`. [`1458492896_metafits.fits`](1458492896_metafits.fits.md) has an integer `HIERARCH STARTTIME`; this one is in the primary header and has a string value. mwalib does not read it, but a reader must neither reject nor truncate it to `REFERENC`
- Numeric cards read as strings ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143)): the ten delay-mode integers, `DELAYMOD`/`BDELMOD` with trailing blanks
- CONTINUE long strings without `LONGSTRN`, including two descriptions that mwalib reports (`DELDESC`, `BDELDESC`)
- NaN in float columns; NUL-padded and entirely-NUL string cells ([fitsio-pure#144](https://github.com/OrbitalCommons/fitsio-pure/issues/144)), e.g. `target_name` = `PSR J1752-2806` + 236 NULs
- Wide rows (1891 bytes) and large repeat counts (`tileset` 256I, `Corrections` 256D)
