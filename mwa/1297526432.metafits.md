# 1297526432.metafits

**Source**: MWATelescope/Marlu test suite (https://github.com/MWATelescope/Marlu), also used in MWATelescope/Birli (https://github.com/MWATelescope/Birli); `tests/data/1297526432_mwax/1297526432.metafits` in both (byte-identical)

**License**: MPL-2.0

**Description**: Minimal MWAX correlator metafits file for a synthetic observation based on the MWAX HydA Gold Observation. Contains only 4 tile inputs (2 antennas x 2 polarizations, `NINPUTS = 4`), making it the smallest metafits file in this directory. `CHANNELS` still lists 24 coarse channels (109 to 132), while `CHANSEL = '8,9'` selects the two (117 and 118) that have gpubox files. TILEDATA has 17 columns: it lacks the `Calib_Delay`, `Calib_Gains` and `Receiver_Types` columns found in the newer metafits files here, and the header has `VERSION = 2.0`. Used by Marlu and Birli for unit testing correlator data I/O.

**Instrument/Mission**: Murchison Widefield Array (MWA), MWAX correlator

## HDU Structure

| HDU | Type     | Dimensions         | EXTNAME  | Description                              |
|-----|----------|--------------------|----------|------------------------------------------|
| 0   | Primary  | (empty)            |          | Observation metadata (GPS time, pointing, channels) |
| 1   | BINTABLE | 17 cols x 4 rows   | TILEDATA | Antenna/tile metadata (positions, gains, delays, flavors) |

## FITS Features Exercised

- Empty primary HDU with extensive metadata headers
- Binary table with mixed column types (integer, float, string, array-in-cell)
- Named extension (EXTNAME = TILEDATA)
- Array-in-cell columns (e.g. Gains with repeat count > 1)
- MWA-specific keywords (GPSTIME, EXPOSURE, CENTCHAN, CHANNELS)
- CONTINUE long-string convention (CHANNELS spans three cards, the last an empty `''` carrying the comment)
