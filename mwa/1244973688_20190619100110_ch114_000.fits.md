**Description**: A real MWAX correlator ("gpubox") file, the first batch (`_000`) of coarse channel 114 of observation 1244973688 (2019-06-19, project `C001`, `CORR_VER = 2`, correlator host `mwax03`), whose metafits is [`1244973688.metafits`](1244973688.metafits.md). Per mwalib's `test_files/1244973688_1_timestep/README.md`, it was cut to the primary HDU and the first timestep's visibility and weights HDUs to save space. Visibilities are ordered `[baseline][finechan][pol][r,i]` and weights `[baseline][pol]` (primary header COMMENTs): 8256 baselines (128 tiles, autocorrelations included) × 128 fine channels of 10 kHz × 4 pols × (r, i) = 1024 values per row.

Both image HDUs are tile-compressed, one tile per row (`ZTILE1 = NAXIS1`, `ZTILE2 = 1`), as `RICE_1` with `ZBITPIX = -32`, so the floats were quantized (`NOISEBIT = 16`, `ZQUANTIZ = 'NO_DITHER'`) and the stored values are not exact:

| HDU | Tiles | RICE_1 tiles | GZIP fallback tiles | Decoded |
|-----|-------|--------------|---------------------|---------|
| 1 visibilities | 8256 | 6216 (per-tile `ZSCALE` up to 630625.48, `ZZERO` down to −6.49 × 10⁹) | 2040, all rows of zeros (`ZSCALE = ZZERO = 0`) | float32, −6.49 × 10⁹ to 8.44 × 10⁹; first values 20113300, 0, 1590216.9, −117793.84 |
| 2 weights | 8256 | 0 | 8256 (every weight is 1.0) | float32, all 1.0 |

The 2040 zero rows are the baselines involving 17 tiles with no data (17 × 111 cross baselines + 136 between them + 17 autos).

[`1244973688_20190619100110_ch114_001.fits`](1244973688_20190619100110_ch114_001.fits.md) is this file with the batch's `MARKER` and `TIME` changed: the data are the same bytes.

## FITS Features Exercised

- Tile-compressed float images from a real instrument ([fitsio-pure#147](https://github.com/OrbitalCommons/fitsio-pure/issues/147)): `RICE_1` with `NO_DITHER` quantization and per-tile `ZSCALE`/`ZZERO`, and the lossless `GZIP_COMPRESSED_DATA` fallback mixed into the same HDU (2040 of 8256 tiles in HDU 1, all 8256 in HDU 2, where `COMPRESSED_DATA` is `1PB(0)`)
- One-row tiles, 8256 per HDU, and a 5.8 MB variable-length heap
- MWAX visibilities as `float32`, unlike [`1297526432_gpubox_ch117.fits`](1297526432_gpubox_ch117.fits.md) (synthetic, uncompressed `int32`) and the legacy [`1101503312_20141201210818_gpubox01_00.fits`](1101503312_20141201210818_gpubox01_00.fits.md) (`int32`, `BSCALE = 0.5`, [fitsio-pure#146](https://github.com/OrbitalCommons/fitsio-pure/issues/146))
- Numeric cards read as strings ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143)): `FINECHAN = 10.` and `INTTIME = 1.` with a trailing decimal point, `MARKER`, `TIME`, `MILLITIM`
- A multi-batch gpubox file name: mwalib takes the batch (`_000`) and channel (`ch114`) from the name
