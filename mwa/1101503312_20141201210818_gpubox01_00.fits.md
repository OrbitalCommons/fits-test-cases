**Description**: A legacy (pre-MWAX) MWA correlator "gpubox" file for observation 1101503312 (2014-12-01), coarse channel file 01. Per mwalib's test README it keeps only the primary HDU and the first timestep's HDU, stored as a tile-compressed image to save space ("lossless, and this only works on data taken > Oct 2014"). The `ZTENSION` comment says the compressed HDU was made by `MWA DataCapture`.

The compressed image is `ZBITPIX = 32` integers with **`BSCALE = 0.5`** in the compressed header (no `BZERO`, no `ZSCALE`/`ZZERO` columns), so a reader must decompress the RICE_1 tiles to `int32` and then halve them. astropy decodes 128 × 66048 values from -7952.5 to 228468.0; 7,153,473 are non-zero. Element `[0][6]` (row 0, column 6) is 83412.0, stored as 166824. mwalib's port onto fitsio-pure 0.22.0 read 166824 there through `read_image_into_buffer`, while cfitsio `ffgpv` and astropy give 83412 ([fitsio-pure#146](https://github.com/OrbitalCommons/fitsio-pure/issues/146)).

The image is `[row = 128 fine channels][66048 = 8256 baselines × 4 pols × 2 (re, im)]` in the legacy correlator's own ordering, which mwalib reorders; `TIME = 1417468096`, `MILLITIM = 0`, `INTTIME = 2.`, `MARKER = 139800`.

**Instrument/Mission**: Murchison Widefield Array (MWA) Phase 1, legacy correlator

## FITS Features Exercised

- `RICE_1` tile compression of a 32-bit integer image (`BYTEPIX = 4`, `BLOCKSIZE = 32`), one tile per image row
- `BSCALE = 0.5` on a compressed image: physical values are half the decoded integers ([fitsio-pure#146](https://github.com/OrbitalCommons/fitsio-pure/issues/146): `read_image_into_buffer` must apply it, as `read_image` does)
- Partial reads of a compressed image: `read_section` / `read_rows` windows, the last tile row, and windows crossing tiles ([fitsio-pure#147](https://github.com/OrbitalCommons/fitsio-pure/issues/147)); with one row per tile, every row is its own tile
- A partial `ffgpv`-style read of N elements from offset K, as mwalib does ([fitsio-pure#146](https://github.com/OrbitalCommons/fitsio-pure/issues/146))
- Numeric header cards read as strings, e.g. `TIME`, `INTTIME = 2.` ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143))
- A string value followed directly by `/` with no space (`PROJID  = 'G0009' / MWA Project Id`)
- Non-compression keywords carried in the compressed header (`TIME`, `MARKER`, `COMMENT`)
- A large heap (14.2 MB) behind a 1 KB table
