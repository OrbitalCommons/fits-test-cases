## FITS Features Exercised

- Looking up an HDU by name that is not there (`VOLTAGEBEAMS`), which must come back as "absent", not as an error
- Mixed-case column names that differ between tables: TILEDATA's `Receiver_Types` and SIGCHAINDATA's `Receiver_type`, and lower-case `gpstime` next to `Alt`, `Az` ([fitsio-pure#145](https://github.com/OrbitalCommons/fitsio-pure/issues/145))
- NUL-padded string cells ([fitsio-pure#144](https://github.com/OrbitalCommons/fitsio-pure/issues/144)): all 256 `TileName`, `Length` and `Receiver_Types` cells, 148 of 256 `Flavors` cells, and all 8 `Receiver_type` cells
- Numeric cards read as strings ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143)), and a non-contiguous `CHANNELS` list
- CONTINUE long strings without `LONGSTRN` (`CHANNELS`, `MWAXSTAT`)
- Wide rows with a large repeat count (`Corrections` 256D)
