# sdc3_0000.uvfits

**Source**: MWATelescope/mwa_hyperdrive test suite (https://github.com/MWATelescope/mwa_hyperdrive), `test_files/sdc3/sdc3_0000.uvfits` (byte-identical)

**License**: MPL-2.0

**Description**: Minimal UVFITS file from the SKA Data Challenge 3 (SDC3) simulation (`TELESCOP = 'SKA1-LOW'`, `ORIGIN = 'casacore'`). Contains a single visibility group in random groups format with 512 antenna entries (`s0000` to `s0511`). Per the upstream README it holds one channel, the first cross-correlation baseline on the first timestep, and one polarisation (XX); the header agrees: 106 MHz (`CRVAL4`), `CRVAL3 = -5` (XX), and the group's baseline is antennas 1 and 2. Used by hyperdrive for UVFITS I/O testing.

**Instrument/Mission**: Square Kilometre Array (SKA) simulation for SDC3

## HDU Structure

| HDU | Type          | Dimensions              | EXTNAME  | Description                              |
|-----|---------------|-------------------------|----------|------------------------------------------|
| 0   | Random Groups | NAXIS=7: NAXIS1=0, then [3,1,1,1,1,1] (COMPLEX, STOKES, FREQ, IF, RA, DEC), PCOUNT=9, GCOUNT=1 | | Single visibility group with 9 random parameters |
| 1   | BINTABLE      | 5 cols x 1 row          | AIPS FQ  | Frequency setup table                    |
| 2   | BINTABLE      | 13 cols x 512 rows      | AIPS AN  | Antenna positions and metadata           |

## FITS Features Exercised

- Random groups format (GROUPS=T, PCOUNT=9, GCOUNT=1)
- Multi-axis data array (NAXIS=7, with NAXIS1=0 as random groups requires, leaving 6 data axes)
- Repeated PTYPE: `PTYPE4` and `PTYPE5` are both `DATE` (day number and day fraction), which readers must sum
- AIPS-convention binary table extensions (FQ, AN)
- Float data (BITPIX=-32)
- Named extensions with spaces in EXTNAME (`AIPS FQ`, `AIPS AN`) and column names with spaces (`IF FREQ`, `CH WIDTH`, `TOTAL BANDWIDTH`)
- A zero-width column: `ORBPARM` in AIPS AN is `0D`
- Blank (all-space) header cards in every HDU
