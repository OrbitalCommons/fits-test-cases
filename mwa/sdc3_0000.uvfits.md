# sdc3_0000.uvfits

**Source**: MWATelescope/mwa_hyperdrive test suite (https://github.com/MWATelescope/mwa_hyperdrive)

**License**: MPL-2.0

**Description**: Minimal UVFITS file from the SKA Data Challenge 3 (SDC3) simulation. Contains a single visibility group in random groups format with 512 antenna entries. Used by hyperdrive for UVFITS I/O testing.

**Instrument/Mission**: Square Kilometre Array (SKA) simulation for SDC3

## HDU Structure

| HDU | Type          | Dimensions              | EXTNAME  | Description                              |
|-----|---------------|-------------------------|----------|------------------------------------------|
| 0   | Random Groups | axes=[3,1,1,1,1,1], PCOUNT=9, GCOUNT=1 | | Single visibility group with 9 random parameters |
| 1   | BINTABLE      | 5 cols x 1 row          | AIPS FQ  | Frequency setup table                    |
| 2   | BINTABLE      | 13 cols x 512 rows      | AIPS AN  | Antenna positions and metadata           |

## FITS Features Exercised

- Random groups format (GROUPS=T, PCOUNT=9, GCOUNT=1)
- Multi-axis data array (6 NAXIS dimensions)
- AIPS-convention binary table extensions (FQ, AN)
- Float data (BITPIX=-32)
- Named extensions with spaces in EXTNAME

**File size**: 57,600 bytes (56.3 KB)
