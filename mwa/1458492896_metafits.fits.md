- Column lookup that must ignore case and report a missing column as status 219 ([fitsio-pure#145](https://github.com/OrbitalCommons/fitsio-pure/issues/145)): this file's CALIBDATA names the delay `Calib_Delay`, where [`1348608128_metafits.fits`](1348608128_metafits.fits.md) has `delay_m`. mwalib's `calibration_fit` reads `delay_m` first and falls back to `Calib_Delay` when that fails, so here the first lookup must fail cleanly
- NUL-padded string cells ([fitsio-pure#144](https://github.com/OrbitalCommons/fitsio-pure/issues/144)): `TileName`, `Length`, `Receiver_Types`, 400 of 512 `Flavors` cells, and the 250-byte VOLTAGEBEAMS strings, two of which (`tle`, `channel_set`) are entirely NUL; `target_name` is `PSR J1455-3330` followed by 236 NULs
- Numeric cards read as strings ([fitsio-pure#143](https://github.com/OrbitalCommons/fitsio-pure/issues/143)), including a 16-digit integer beyond 32 bits (`CALFIT = 1774436148689156`), a keyword with no value (`FILENAME=  / Hyperdrive fit filename` in CALIBDATA), and empty strings (`MWB_ENAB= ''`)
- CONTINUE long strings without `LONGSTRN` (`RECVRS`, `CHANNELS`)
- Seven HDUs mixing binary tables and a 3-D image extension; wide rows (1891 bytes) and large repeat counts (`tileset` 256I, `Corrections` 256D)
- COMMENT and HISTORY blocks
