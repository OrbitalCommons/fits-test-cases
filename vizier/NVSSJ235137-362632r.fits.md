# NVSSJ235137-362632r.fits

## Source

VizieR astronomical catalog service (https://vizier.cds.unistra.fr/). ATCA (Australia
Telescope Compact Array) radio map of the ultra-steep-spectrum source 2351-362 at 2368 MHz,
observed 2003-07-29 (OBSERVER = 'CDB,RWH'). It is not an NVSS image: the file is named
after the source's NVSS designation, following the convention of VizieR catalogue
J/MNRAS/347/837 (De Breuck et al., 2004, "A search for distant radio galaxies from SUMSS
and NVSS - I"), whose `fits/` directory holds one `NVSS...r.fits` radio map per source.
This file is byte-identical to
https://cdsarc.cds.unistra.fr/ftp/J/MNRAS/347/837/fits/NVSSJ235137-362632r.fits
(catalogue page: https://cdsarc.cds.unistra.fr/viz-bin/cat/J/MNRAS/347/837). Processed
through Miriad and exported via AIPS. It is also identical to
`samples/vizier/NVSSJ235137-362632r.fits` in the test-file archive of the Rust
[fitsrs](https://github.com/cds-astro/fitsrs) crate (https://alasky.cds.unistra.fr/Aladin-Lite-test-files/fits-rs-test-files.tar).

## HDU Structure

| HDU | Type     | Details                                  | BITPIX |
|-----|----------|------------------------------------------|--------|
| 0   | Primary  | 1024 x 1024 x 1 x 1 (4-D image)        | -32    |
| 1   | BINTABLE | 39 columns x 1 row (EXTNAME: AIPS MF)   | 8      |

Primary image is 4,194,304 bytes (NAXIS1 x NAXIS2 = 1024 x 1024); binary table row width
is 156 bytes. All 39 columns are `1E`.

## FITS Features Exercised

- **4-dimensional image** (`NAXIS = 4`) with degenerate axes (NAXIS3=1, NAXIS4=1)
  for frequency (FREQ-LSR) and Stokes parameters
- **NCP projection** (`CTYPE1 = RA---NCP`) -- a legacy WCS projection type
- **CROTA keywords** on all four axes
- **BUNIT = JY/BEAM** flux unit declaration
- **DATAMAX / DATAMIN** pixel range keywords
- **AIPS MF binary table extension** with 39 source-fitting columns (Gaussian model
  parameters, errors, deconvolved sizes)
- **Extensive HISTORY** from Miriad pipeline (ATLOD, UVSPLIT, INVERT, CLEAN, RESTOR, FITS)
- **BLOCKED** keyword (tape-era artifact)
- **EPOCH** instead of EQUINOX for the coordinate equinox (`EPOCH = 2000`)
- **ORIGIN** value `'AIPSpc008328     UN-REGISTERED!!!!!!! 31DEC03'`
- AIPS MF table header ends with AIPS keywords that carry no comments (`REVISION`, `DEPTH1`-`DEPTH5`,
  `REALRMS`)
