## Description

A multi-extension file containing three different data types in a single FITS file: 8-bit unsigned byte, 32-bit signed integer, and 32-bit float. Each HDU has constant pixel values, making this useful for type-handling verification.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | UINT8 | 8 | 2 x 2 | Constant 128 (u8) |
| 2 | IMAGE | FLOAT32 | -32 | 4 x 4 | Constant 3.14 (f32) |
| 3 | IMAGE | INT32 | 32 | 3 x 3 | Constant -42 (i32) |

## FITS Features Exercised

- Multiple BITPIX types in one file (8, 32, -32)
- Small image arrays
- Negative integer values
- Multi-extension file (3 image extensions)
- EXTNAME keyword
