Generated by the [meter-sim](https://github.com/CosmicFrontierLabs/focalplane) (now CosmicFrontierLabs/focalplane) simulator test suite ([`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs) `test_checkerboard_11x13_blocks`). The writer that produced this file, [`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs), was removed in [focalplane #78](https://github.com/CosmicFrontierLabs/focalplane/pull/78) (2026-05-04). ## Description

An 88x104 pixel checkerboard pattern with 8-pixel blocks arranged in an 11x13 grid. The non-square grid dimensions make this useful for detecting axis-swap bugs in I/O code.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | CHECKERBOARD_8PX_11X13 | 8 | 88 x 104 | Checkerboard (0/255) |

## FITS Features Exercised

- 8-bit unsigned integer data (BITPIX=8)
- Non-square image with asymmetric block grid
- EXTNAME keyword
- Tests axis ordering correctness
