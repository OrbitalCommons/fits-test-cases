# extreme_ratios_panorama_column_1d.fits

## Provenance

Generated by the [meter-sim](https://github.com/CosmicFrontierLabs/meter-sim) simulator test suite (`simulator/src/io/fits.rs::test_extreme_aspect_ratios`). Synthetic test data.

## Description

Tests extreme aspect ratios including nearly-1D arrays. Contains panoramic (wide), columnar (tall), single-row, and single-column images. Exercises edge cases in dimension handling.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | COLUMN | 32 | 50 x 1000 | Constant 1024 (i32) |
| 2 | IMAGE | PANORAMA | 32 | 1000 x 50 | Constant 512 (i32) |
| 3 | IMAGE | ROW | -32 | 500 x 1 | Constant 0.5 (f32) |
| 4 | IMAGE | COL | -32 | 1 x 500 | Constant 0.25 (f32) |

## FITS Features Exercised

- Extreme aspect ratio images (20:1, 1:20, 500:1, 1:500)
- Mixed integer and floating point types in one file
- 32-bit signed integer (BITPIX=32) and 32-bit float (BITPIX=-32)
- Near-degenerate dimensions (width=1 or height=1)
- Multi-extension file (4 image extensions)
