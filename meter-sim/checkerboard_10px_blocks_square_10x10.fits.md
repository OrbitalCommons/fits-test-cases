## Description

A 100x100 pixel checkerboard pattern with 10x10 blocks in a 10x10 grid. Each block is either 0 (black) or 255 (white). The bottom-left block (the first stored pixel under the FITS bottom-left origin) is 255. Useful for testing spatial accuracy, coordinate conventions, and image orientation.

## HDU Structure

| 1 | IMAGE | CHECKERBOARD_10PX_10X10 | 8 | 100 x 100 | Checkerboard (0/255) |
