# gradients_all_orientations_labeled.fits

## Provenance

Generated by the [meter-sim](https://github.com/CosmicFrontierLabs/focalplane) (now CosmicFrontierLabs/focalplane) simulator test suite ([`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs) `test_combined_gradients`). Synthetic test data.

> **History**: meter-sim was renamed [focalplane](https://github.com/CosmicFrontierLabs/focalplane). The writer that produced this file, [`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs), was removed in [focalplane #78](https://github.com/CosmicFrontierLabs/focalplane/pull/78) (2026-05-04). [Issue #77](https://github.com/CosmicFrontierLabs/focalplane/issues/77) found that it wrote images upside down relative to the FITS bottom-left origin, so check orientation against the pixel data, not the file name.

## Description

Four gradient images in all orientations: vertical dark-to-bright (bottom to top), vertical bright-to-dark, horizontal dark-to-bright (left to right), and horizontal bright-to-dark. The EXTNAME labels give the orientation the generator intended. The two horizontal HDUs match their labels, but **both vertical HDUs are stored upside down relative to their labels** under the FITS bottom-left origin, because the writer flipped images vertically ([focalplane#77](https://github.com/CosmicFrontierLabs/focalplane/issues/77)). Useful for verifying FITS coordinate conventions and image-flipping behaviour, with expected values taken from the table below rather than the EXTNAMEs.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | VERT_BRIGHT_BOT_DARK_TOP | -32 | 128 x 256 | Vertical gradient, 0.0 at the bottom (first stored row) to 1.0 at the top: **the reverse of its EXTNAME** |
| 2 | IMAGE | HORIZ_BRIGHT_LEFT_DARK_RIGHT | -32 | 256 x 128 | Horizontal gradient 1.0→0.0 |
| 3 | IMAGE | VERT_DARK_BOT_BRIGHT_TOP | -32 | 128 x 256 | Vertical gradient, 1.0 at the bottom (first stored row) to 0.0 at the top: **the reverse of its EXTNAME** |
| 4 | IMAGE | HORIZ_DARK_LEFT_BRIGHT_RIGHT | -32 | 256 x 128 | Horizontal gradient 0.0→1.0 |

## FITS Features Exercised

- 32-bit floating point data (BITPIX=-32)
- Multi-extension file (4 image extensions)
- FITS coordinate system convention testing
- Image orientation verification
- Non-square images
