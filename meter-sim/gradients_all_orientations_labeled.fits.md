# gradients_all_orientations_labeled.fits

## Provenance

Generated by the [meter-sim](https://github.com/CosmicFrontierLabs/meter-sim) simulator test suite (`simulator/src/io/fits.rs::test_combined_gradients`). Synthetic test data.

## Description

Four gradient images in all orientations: vertical dark-to-bright (bottom to top), vertical bright-to-dark, horizontal dark-to-bright (left to right), and horizontal bright-to-dark. The EXTNAME labels clearly indicate expected orientation. Useful for verifying FITS coordinate conventions (origin at bottom-left) and image flipping behavior.
