Generated by the [meter-sim](https://github.com/CosmicFrontierLabs/focalplane) (now CosmicFrontierLabs/focalplane) simulator test suite ([`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs) `test_non_square_array_export`). The writer that produced this file, [`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs), was removed in [focalplane #78](https://github.com/CosmicFrontierLabs/focalplane/pull/78) (2026-05-04). ## Description

Tests writing and reading non-square image arrays with various aspect ratios. All pixel values are constant within each HDU, making it useful for verifying dimension handling during round-trip I/O.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions (NAXIS1 x NAXIS2) | Content |
|-----|------|---------|--------|------------------------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | TALL | -64 | 100 x 200 | Constant 2.0 (f64) |
| 2 | IMAGE | WIDE | -64 | 200 x 100 | Constant 1.0 (f64) |
| 3 | IMAGE | SQUARE | -64 | 150 x 150 | Constant 3.0 (f64) |

## FITS Features Exercised

- Multi-extension image file (3 image extensions)
- Non-square image arrays
- 64-bit floating point data (BITPIX=-64)
- EXTNAME keyword for HDU identification
- Round-trip read/write verification
