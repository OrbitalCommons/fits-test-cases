## Description

A 256x256 horizontal gradient image ranging from 0 (left) to 65535 (right), stored as 32-bit integers. Useful for verifying horizontal axis orientation and pixel value scaling.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | HORIZONTAL_GRADIENT | 32 | 256 x 256 | Gradient 0→65535 left to right |

## FITS Features Exercised

- 32-bit signed integer data (BITPIX=32) storing unsigned 16-bit range
- Square image array
- Horizontal gradient for axis orientation testing
- EXTNAME keyword
