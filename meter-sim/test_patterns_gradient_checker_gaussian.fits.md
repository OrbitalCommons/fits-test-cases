# test_patterns_gradient_checker_gaussian.fits

## Provenance

Generated by the [meter-sim](https://github.com/CosmicFrontierLabs/meter-sim) simulator test suite (`simulator/src/io/fits.rs::test_gradient_and_noise_patterns`). Synthetic test data.

## Description

A collection of common test patterns in a single file: horizontal gradient, vertical gradient, checkerboard, and a Gaussian blob. Exercises multiple data types and image sizes. The Gaussian blob is a synthetic PSF-like feature useful for centroiding and photometry tests.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | VERTICAL_GRADIENT | 32 | 100 x 256 | Gradient 0→65535 bottom to top |
| 2 | IMAGE | GAUSSIAN_BLOB | -32 | 64 x 64 | 2D Gaussian (σ=10, peak=1.0) |
| 3 | IMAGE | CHECKERBOARD_16PX | 8 | 128 x 128 | Checkerboard (0/255, 16px blocks) |
| 4 | IMAGE | HORIZONTAL_GRADIENT | 32 | 256 x 100 | Gradient 0→65535 left to right |

## FITS Features Exercised

- Multiple BITPIX types in one file (8, 32, -32)
- Multi-extension file (4 image extensions)
- Gradient patterns for orientation testing
- Gaussian PSF-like feature
- Checkerboard pattern for spatial accuracy
- Non-square images
