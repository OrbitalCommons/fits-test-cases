## Description

A 256x256 vertical gradient stored as 32-bit integers. **Despite the file name, the data runs the other way**: the first row stored (`NAXIS2` index 1, the bottom under the FITS bottom-left origin) is 65535, and the last row (the top) is 0. A standard viewer (astropy, ds9) shows it bright at the bottom and dark at the top. The generator meant dark-bottom, bright-top, but its writer flipped images vertically ([focalplane#77](https://github.com/CosmicFrontierLabs/focalplane/issues/77)). Useful for vertical-orientation tests, as long as the expected answer comes from the data above, not the name.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | VERTICAL_GRADIENT | 32 | 256 x 256 | Gradient 65535 at the bottom (first stored row) to 0 at the top |

## FITS Features Exercised

- 32-bit signed integer data (BITPIX=32) storing unsigned 16-bit range
- Square image array
- Vertical gradient for FITS origin convention testing
- EXTNAME keyword
