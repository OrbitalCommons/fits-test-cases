# roundtrip_f64_multi_hdu.fits

## Provenance

Generated by the [meter-sim](https://github.com/CosmicFrontierLabs/focalplane) (now CosmicFrontierLabs/focalplane) simulator test suite ([`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs) `test_fits_roundtrip_f64`). Synthetic test data.

> **History**: meter-sim was renamed [focalplane](https://github.com/CosmicFrontierLabs/focalplane). The writer that produced this file, [`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs), was removed in [focalplane #78](https://github.com/CosmicFrontierLabs/focalplane/pull/78) (2026-05-04). [Issue #77](https://github.com/CosmicFrontierLabs/focalplane/issues/77) found that it wrote images upside down relative to the FITS bottom-left origin, so check orientation against the pixel data, not the file name.

## Description

A minimal multi-HDU file with two 64-bit floating point images used for round-trip read/write verification. Contains small arrays with known values (1.5, 2.5, 3.7) that can be checked for exact floating-point fidelity.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | IMAGE1 | -64 | 4 x 3 | Constant 1.5 (f64) |
| 2 | IMAGE | IMAGE2 | -64 | 2 x 2 | Sparse: 2.5 and 3.7 on diagonal |

## FITS Features Exercised

- 64-bit floating point data (BITPIX=-64)
- Multi-extension file
- Small arrays for exact value verification
- Round-trip fidelity testing
- EXTNAME keyword
