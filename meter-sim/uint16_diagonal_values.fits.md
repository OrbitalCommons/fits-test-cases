# uint16_diagonal_values.fits

## Provenance

Generated by the [meter-sim](https://github.com/CosmicFrontierLabs/focalplane) (now CosmicFrontierLabs/focalplane) simulator test suite ([`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs) `test_typed_fits_uint16`). > **History**: meter-sim was renamed [focalplane](https://github.com/CosmicFrontierLabs/focalplane). The writer that produced this file, [`simulator/src/io/fits.rs`](https://github.com/CosmicFrontierLabs/focalplane/blob/35a4a24371c994ee041c39b750893fb17dbee9e9/simulator/src/io/fits.rs), was removed in [focalplane #78](https://github.com/CosmicFrontierLabs/focalplane/pull/78) (2026-05-04). ## Description

A minimal 3x3 image with non-zero values on the diagonal (100, 1000, 65535) stored as 32-bit integers representing unsigned 16-bit data. Tests the FITS convention of storing unsigned 16-bit values in a signed 32-bit container.

## HDU Structure

| HDU | Type | EXTNAME | BITPIX | Dimensions | Content |
|-----|------|---------|--------|------------|---------|
| 0 | Primary | — | 8 | empty | Empty primary |
| 1 | IMAGE | UINT16_IMAGE | 32 | 3 x 3 | Diagonal: 100, 1000, 65535 |

## FITS Features Exercised

- Unsigned 16-bit data stored as BITPIX=32
- Small sparse array with known values
- EXTNAME keyword
