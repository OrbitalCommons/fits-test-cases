**Description**: A random-groups UVFITS file written by Birli v0.5.0 (`COMMENT Created by birli v0.5.0`, `SOFTWARE = 'birli'`, `GITLABEL = 'v0.5.0'`), whose UVFITS writer is Marlu's. Per hyperdrive's `test_files/1090008640/README.md`, it was derived with Birli's default settings from a gpubox file of observation 1090008640 (EoR-0, high band, zenith) cut to one timestep (GPS 1090008658), and a flag was then added to baseline 12 (tiles 0 and 12) on channel 2 for testing. hyperdrive's uvfits reader tests use it.

There are 8256 groups: one timestep of 8256 baselines (128 tiles, autocorrelations included), each with 5 parameters and 32 channels × 4 polarisations × (re, im, weight) as `float32` (1556 bytes per group). Group 0 has raw parameters `UU = VV = WW = 0`, `BASELINE = 257`, `DATE = −0.1592361182` (`+ PZERO5 = 2456860.5` gives 2456860.340763882) and first visibility (53557.855, 4.3092e-07, 8.0). The last group is `BASELINE = 32896`. 4 weights are negative. The AIPS AN table starts at byte 12,853,440.

Unlike cotter's [`../mwa/1196175296.uvfits`](../mwa/1196175296.uvfits.md), Birli writes floats in E format (`BSCALE  =      1.000000000E+00`), some WCS values as integers (`CRVAL3  =                   -5`), and adds `FRAME`, `TIMESYS`, `EXTVER`, `NO_IF` and `XYZHAND` to the AN table.

**Instrument/Mission**: Murchison Widefield Array (MWA), via Birli
