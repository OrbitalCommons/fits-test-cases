# skv1678175163788.fits

## Source

NASA SkyView query result for the 408 MHz all-sky radio continuum survey
(Haslam et al., 1982). The filename encodes the SkyView request ID / timestamp.
Retrieved 2023-03-07. Original data from Max Planck Institute for Radio Astronomy.

## HDU Structure

| HDU | Type    | Dimensions | Data Size  |
|-----|---------|------------|------------|
| 0   | Primary | 300 x 300  | 360,000 B  |

1 HDU total. Single 2D floating-point image (BITPIX=-32).

## FITS Features Exercised

- Single-HDU image-only file (no extensions)
- 32-bit floating-point pixel data
- WCS keywords: RA---TAN / DEC--TAN projection, FK5 J2000 coordinates
- BUNIT = "K" (Kelvins brightness temperature)
- Extensive COMMENT and HISTORY cards from SkyView processing pipeline
- SURVEY = "408mhz" metadata
- Structurally identical layout to bonn.fits (same SkyView pipeline)
