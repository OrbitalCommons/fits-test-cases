# bonn.fits

## Source

Bonn 1420 MHz Radio Survey data, generated by P. Reich and W. Reich at the
Max Planck Institute for Radio Astronomy. Retrieved via NASA SkyView on
2023-03-06. Observed with the Stockert 25m telescope at 1420 MHz continuum.

## HDU Structure

| HDU | Type    | Dimensions | Data Size  |
|-----|---------|------------|------------|
| 0   | Primary | 300 x 300  | 360,000 B  |

1 HDU total. Single 2D floating-point image (BITPIX=-32).

## FITS Features Exercised

- Single-HDU image-only file (no extensions)
- 32-bit floating-point pixel data
- WCS keywords: RA---TAN / DEC--TAN projection, FK5 J2000 coordinates
- BUNIT = "mK" (millikelvins brightness temperature)
- Extensive COMMENT and HISTORY cards from SkyView processing pipeline
- SURVEY, TELESCOP, and DATE-MAP instrument metadata
