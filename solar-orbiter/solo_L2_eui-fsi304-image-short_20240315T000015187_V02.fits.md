## FITS Features Exercised

- `BLANK = -32768` on a scaled integer image: astropy and fitsio-pure's physical reads return NaN for the 9,322,691 blank pixels. The Rust `fitsio` crate's `read_image` (cfitsio with a null value of 0) returns them as 0, so readers disagree here unless they handle nulls the same way
- `BSCALE = 0.0`, a degenerate scale. Every non-blank stored value is also 0, so a reader that applies the 0 and one that treats it as unset and substitutes 1 both get 0: this file shows that a zero `BSCALE` must not crash or divide by zero, but it cannot tell those two readings apart
- Highly compressible `RICE_1` (one-row tiles of mostly identical values)
- Non-square 3040 × 3072 image, 227-card header with helioprojective WCS
