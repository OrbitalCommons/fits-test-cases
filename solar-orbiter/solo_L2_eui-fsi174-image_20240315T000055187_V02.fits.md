## FITS Features Exercised

- Real-instrument `RICE_1` tile-compressed image: 16-bit integers (`ZBITPIX = 16`, `BYTEPIX = 2`) with floating `BSCALE = 0.13824101714527334` and `BZERO = 4527.475341200829`, so readers return `float32` physical values
- `BLANK = -32768` declared (no pixel in this frame uses it)
- Non-square image: 3040 columns × 3072 rows (`ZNAXIS1 = 3040`, `ZNAXIS2 = 3072`), so an axis-order mistake shows as a shear, not a transpose
- 3072 one-row tiles (`ZTILE1 = 3040`, `ZTILE2 = 1`)
- A 236-card header with helioprojective WCS (`HPLN-TAN`/`HPLT-TAN`) and spacecraft ephemeris keywords
- Empty primary HDU carrying `CHECKSUM`/`DATASUM`; `EXTNAME = COMPRESSED_IMAGE`
