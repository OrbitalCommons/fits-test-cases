# WFPC2u5780205r_c0fx.fits

## Source

HST WFPC2 calibrated science data for NGC 4151, observed 1999-02-20 with the
FR533P15 linear ramp filter (LRF at 4877 A). 300-second exposure from proposal
8019 (PI not listed). Converted from GEIS format by STScI (rootname u5780205r).
This is the NASA FITS sample `WFPC2u5780205r_c0fx.fits`
(https://fits.gsfc.nasa.gov/samples/WFPC2u5780205r_c0fx.fits), byte-identical,
and the same file as `nasa-samples/HST_WFPC_II.fits`.

## History

Until 2026-10-11 this corpus held a corrupted copy (1,486,895 bytes): a text
round trip had turned most bytes >= 0x80 into the four ASCII characters `\xNN`,
changed CR LF to LF, dropped spaces and tabs before newlines and removed the
trailing padding, leaving garbage image data and the ASCII table off its block
boundary. It was replaced with the GSFC original, which reproduces the
corrupted copy exactly under those transformations.

## HDU Structure

| HDU | Type    | Dimensions      | Data Size  |
|-----|---------|-----------------|------------|
| 0   | Primary | 200 x 200 x 4  | 640,000 B  |
| 1   | TABLE (ASCII) | 49 cols x 4 rows | 3,184 B |

2 HDUs total. HDU 0 is a 3D floating-point image cube (BITPIX=-32,
NAXIS1 x NAXIS2 x NAXIS3 = 200 x 200 x 4) with the 4 groups stored as the
third axis (SDASMGNU=4, CTYPE3="GROUP_NUMBER"). HDU 1 is an ASCII table
(EXTNAME `u5780205r_cvt.c0h.tab`, 796-byte rows) holding the per-group
parameters of the original GEIS file.

## FITS Features Exercised

- 3D image cube (NAXIS=3) representing 4 WFPC2 detector groups
- Converted GEIS multi-group format (OPSIZE, SDASMGNU keywords)
- 32-bit floating-point pixel data with BSCALE=1/BZERO=0
- Full WCS with CD matrix and RA---TAN/DEC--TAN projection
- Complete WFPC2 calibration pipeline keywords and HISTORY records
- LRFWAVE keyword for linear ramp filter wavelength
- Duplicate ORIGIN keyword (STScI-STSDAS and NOAO-IRAF)
- Large header (262 cards in HDU 0)
