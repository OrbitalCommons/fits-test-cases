# WFPC2u5780205r_c0fx.fits

## Source

HST WFPC2 calibrated science data for NGC 4151, observed 1999-02-20 with the
FR533P15 linear ramp filter (LRF at 4877 A). 300-second exposure from proposal
8019 (PI not listed). Converted from GEIS format by STScI (rootname u5780205r).

## HDU Structure

| HDU | Type    | Dimensions      | Data Size  |
|-----|---------|-----------------|------------|
| 0   | Primary | 200 x 200 x 4  | 640,000 B  |

1 HDU total. Single 3D floating-point image cube (BITPIX=-32) with 4 groups
stored as the third axis (SDASMGNU=4, CTYPE3="GROUP_NUMBER").

## FITS Features Exercised

- 3D image cube (NAXIS=3) representing 4 WFPC2 detector groups
- Converted GEIS multi-group format (OPSIZE, SDASMGNU keywords)
- 32-bit floating-point pixel data with BSCALE=1/BZERO=0
- Full WCS with CD matrix and RA---TAN/DEC--TAN projection
- Complete WFPC2 calibration pipeline keywords and HISTORY records
- LRFWAVE keyword for linear ramp filter wavelength
- Duplicate ORIGIN keyword (STScI-STSDAS and NOAO-IRAF)
- Large header (~240 cards)
